# CRM Playwright Project

Playwright end-to-end tests for the Odoo CRM workflows in this project.

## Setup

1. Install Node.js (LTS).
2. Install dependencies:

   ```sh
   npm ci
   npx playwright install chromium
   ```

3. Copy `TestData/login_data.example.json` to `TestData/login_data.json` and enter the Odoo test account credentials. The real credentials file is ignored by Git.

## Run tests

Run the full configured suite:

```sh
npx playwright test
```

In PowerShell, use `npx.cmd playwright test` if script execution policy blocks `npx.ps1`.

Run a single workflow project:

```sh
npx playwright test --project=CreateActivity
npx playwright test --project=AssignQuotationToOpportunity
npx playwright test --project=MoveOpportunityToProposition
npx playwright test --project=MoveOpportunityToWon
```

The assignment and stage-change projects run their required setup projects first. The tests create and update CRM records in the configured Odoo tenant, so use a test database/account.

Test data files (`customer_data.json`, `activity_data.json`, and `opportunity_data.json`) are generated by the setup tests and are not committed.

## GitHub Actions

Push and pull-request checks install dependencies and list the configured tests. They do not log in to Odoo or change CRM records. Run the end-to-end suite locally with credentials configured as above.
